# Realistic Agent Loop Fixture

This fixture models a multi-session AWG project with intentionally mixed graph health.

It demonstrates:

- active and completed tasks
- completed work with and without evidence
- accepted and proposed decisions
- active risks and blockers linked to completed work
- unanswered questions
- stale review metadata
- duplicate-looking nodes
- orphan nodes
- file and command anchors
- completed, blocked, and unfinished agent runs
- run notes and evidence

Use it for CLI tests, docs examples, manual viewer inspection, and future demos of handoff quality and agent-loop diagnostics.
